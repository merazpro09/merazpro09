## 👋 About

Meraz.Pro is a small web and automation agency run by **Merazul Islam**. We help local and service businesses get found on Google and in AI search (ChatGPT, Gemini, Google AI Overviews), turn visitors into leads, and follow up with every lead automatically.

This GitHub profile holds clean, sanitized demos of the kind of work we ship for clients. No client code or credentials live here.

## 🛠️ What we do

- **WordPress websites**: fast, mobile-first sites built with Elementor or custom themes
- **Local SEO**: Google Business Profile setup, citations, on-page SEO and schema
- **AI search readiness**: structured data, llms.txt and content that AI assistants can cite
- **GoHighLevel automation**: lead capture, pipelines, follow-ups, booking reminders
- **AI chatbots**: website assistants trained on your own content that book calls
- **Payment integrations**: WooCommerce and Bangladeshi gateways such as SSLCommerz
